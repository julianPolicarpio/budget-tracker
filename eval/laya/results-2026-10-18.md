# Laya on Split text: dev-split results, 2026-10-18

Status: **dev split only.** The router and thresholds below were chosen on these
rows. The held-out test split (owner-written phrasings) has not been run yet, so
no number here is a held-out claim.

## Setup

- Model: `@receptron/laya` 0.1.2, revision `68f27dfe5a27a54fb2b1fefc432f43f972e90868`, CPU, English model.
- Corpus: `eval/laya/corpus.jsonl`, 234 authored cases, all `dev`; 142 English,
  92 Taglish; 12 tags. Written without reading the parser or catalogue terms.
- Runner: `src/routes/api/intent/laya.eval.test.ts`, which validates answers with
  the production `validChoice` and treats > 750 ms as the route's fallback.
- Machine: 8 GB Apple Silicon Mac. Brave quit; before loading, free+inactive
  was 2.19 GB, `memory_pressure` reported 54 % free, and swap use was 1.15 GB.

## How the eval models the app

Text reaches the model only when the deterministic parser cannot decide. When
the parser asks for a category ("coffee 140"), the screen offers category chips
that log it as spending, and the model is consulted only if the user taps
**Continue**. The runner models that tap: a case whose true intent is plain
spending stays with the spending flow; every other undecided case goes to the
model. This uses the label to stand in for the user's own knowledge of what
they meant.

## Confidence is not usable

With 16 options, the model's top probability is 1.000 at every quartile. On
v1, at probability ≥ 0.9 it was right on 32 of 51 non-`unclear` answers, and 17
of the 51 would have opened a dangerous form.

## Auto-open rule (`src/lib/actions/auto-open.ts`)

`chooseThresholds` requires zero dangerous opens, ≥ 95 % precision and ≥ 3 opens
per class. On v2 it allows **`add-trip` only** (11/11 correct opens), at
probability ≥ 0.95 and margin ≥ 0.5. The same 11/11 holds at 0.75 and 0.9, so
the allowlist does the safety work, not the probability threshold.
`record-refund` opened 7 times with 1 dangerous; other candidates had too few
confident opens. Every other model answer stays a ranked choice.

## Cost on this Mac

- Model download: 1.6 GB on disk, 656 s.
- Cold load from cache: 5 s to `ready`; RSS 844 MB idle after load.
- Peak RSS during runs: 1,541 MB (v1), 1,579 MB (v2).

## Gates from the plan

- **Training gate tripped**: model accuracy 46 % is below the 70 % bar. No
  fine-tuning was done. 234 cases across 17 actions is about 14 per action, too
  few to train on and still hold out a fair test.
- **Taglish below 50 %** (19/60). A `laya-multilingual` comparison was not run
  (another ~1.6 GB download); it is the first thing to try if Taglish matters.
